# Computer-vision stack for the ON-SITE detection machine only.
#
# Install this ON TOP of requirements.txt on the PC that sits with the cameras:
#
#     pip install -r requirements.txt -r requirements-detection.txt
#
# For a SERVER that runs detectors, use requirements-detection-server.txt
# instead -- opencv-python below needs libGL.so.1, which slim containers lack.
# First run additionally downloads the YOLOv8 weights (yolov8n and yolov8n-pose,
# a few MB each), so allow for that on a metered connection.
numpy
# Replaces the headless build in requirements.txt - watch_* --debug opens a
# cv2.imshow preview window, which headless cannot do. Both wheels install the
# same cv2 module, so uninstall the other one first:
#     pip uninstall -y opencv-python-headless && pip install opencv-python
opencv-python
torch
ultralytics
lap  # ultralytics' ByteTrack/BoT-SORT (watch_* --tracker); auto-installs otherwise
